The test behind it

A directed graph has an Euler path exactly when its edges form one connected piece (ignoring direction) and every node has in-degree equal to out-degree, except possibly one start node with out = in + 1 and one end node with in = out + 1. If every node is balanced, the path is a circuit and can start anywhere.
